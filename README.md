# Minecraft Plugin — Grimório da Antimagia

Grimório da Antimagia é um Minecraft plugin para Paper 1.21 que adiciona um grimório interativo, habilidades de anti-magia equipáveis, uma hotbar de poderes e a transformação União Demoníaca inspirada em Asta.

## Install

1. Compile o projeto com Java 21 e Maven:

   `mvn clean package`

2. Copie o arquivo `target/plugin.jar` para a pasta `plugins` do seu servidor Paper.

3. Inicie ou reinicie o servidor.

4. Entre no servidor. O plugin entrega automaticamente um Grimório de Anti-Magia ao jogador caso ele ainda não possua um.

## Use

1. Use o comando `/grimorio` ou clique com o botão direito no grimório para abrir o menu.

2. Clique em uma habilidade para equipá-la ou desequipá-la. O menu permite equipar até oito habilidades.

3. As habilidades equipadas são colocadas automaticamente nos espaços livres da hotbar.

4. Segure uma habilidade equipada e clique com o botão direito para ativá-la.

5. Use o menu para ativar a União Demoníaca. A ativação possui uma sequência visual de quatro segundos com partículas, sons e mensagens.

6. Clique novamente na opção da União Demoníaca para desativá-la.

Habilidades incluídas:

- Voo da Asa Negra
- Corte Anti-Magia
- Divisor Negro
- Meteoro Negro
- Percepção de Ki
- Espada do Habitante
- Espada Destruidora
- Defesa Negra
